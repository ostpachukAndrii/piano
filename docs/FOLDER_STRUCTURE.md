## 🟢 src-leptos/ - Frontend (Leptos WASM)

**Purpose:** Browser-based UI built with Leptos framework, compiled to WebAssembly.

```
src-leptos/
├── Cargo.toml              # Frontend dependencies (leptos, wasm-bindgen, web-sys)
├── Trunk.toml              # Trunk build configuration
├── index.html              # HTML entry point for WASM app
├── server.js               # Node.js dev server (optional)
├── dist/                   # Build output (generated by Trunk)
└── src/
    ├── main.rs             # WASM entry point - mounts App component
    ├── lib.rs              # Library exports
    ├── app.rs              # Root App component - layout and routing
    ├── components/         # UI components (Atomic Design)
    ├── hooks/              # Leptos hooks for state management
    ├── models/             # Frontend data structures
    ├── utils/              # Utility functions
    ├── styles/             # CSS stylesheets
    └── tauri/              # Tauri command bindings (for Tauri mode)
```

### 🧩 src-leptos/src/components/ - UI Components

**Architecture:** Atomic Design Pattern (Atoms → Molecules → Organisms → Containers)

```
components/
├── mod.rs                  # Module exports
├── atoms/                  # Smallest UI elements (no logic)
├── molecules/              # Compositions of 2-3 atoms
├── organisms/              # Complex layouts
└── containers/             # Smart components with hooks
```

#### ⚛️ atoms/ - Basic SVG Elements

| File | Purpose | Props |
|------|---------|-------|
| `notehead.rs` | SVG ellipse for note head | x, y, filled (bool) |
| `stem.rs` | Vertical line for note stem | x, y, direction (up/down), length |
| `clef.rs` | Treble/Bass clef symbol | clef_type, x, y |
| `staff_lines.rs` | 5 horizontal staff lines | x, y, width |
| `accidental.rs` | Sharp/Flat/Natural symbols | x, y, accidental_type |
| `bar_line.rs` | Vertical measure separator | x, y1, y2 |
| `ledger_line.rs` | Lines above/below staff | x, y, width |
| `rest.rs` | Rest symbol (quarter, half, etc.) | x, y, duration |
| `playhead.rs` | Current position indicator | x, y, height |
| `beam.rs` | Connects 8th/16th notes | x1, y1, x2, y2 |
| `time_signature.rs` | Time notation (4/4, 3/4) | x, y, numerator, denominator |
| `key_signature.rs` | Key notation | x, y, key |

#### 🧬 molecules/ - Composite Components

| File | Purpose | Composition |
|------|---------|-------------|
| `note.rs` | Complete note display | Notehead + Stem + Accidental |
| `measure.rs` | Notes within bar lines | Notes + BarLine |
| `midi_device_selector.rs` | MIDI device dropdown | Select + Button + Status |
| `feedback_badge.rs` | Correct/Wrong indicator | Badge with color |
| `virtual_keyboard.rs` | On-screen piano keys | Key elements |
| `streak_counter.rs` | Consecutive correct count | Number + Label |
| `metronome_display.rs` | BPM and beat indicator | Number + Animation |
| `duration_indicator.rs` | Note length display | Icon + Label |
| `chord_tooltip.rs` | Chord name popup | Text tooltip |

#### 🏗️ organisms/ - Complex Layouts

| File | Purpose | Contains |
|------|---------|----------|
| `staff.rs` | Single staff (treble or bass) | StaffLines + Clef + Notes |
| `grand_staff.rs` | Piano grand staff | Treble Staff + Bass Staff + Brace |
| `timeline_viewer.rs` | Lesson progress timeline | Notes list + Playhead |
| `performance_stats.rs` | Session statistics display | Accuracy + Streak + Time |
| `midi_input_display.rs` | Active notes visualization | Note indicators |
| `measure_group.rs` | Multiple measures | Measures + BarLines |

#### 📦 containers/ - Smart Components

| File | Purpose | Hooks Used |
|------|---------|------------|
| `lesson_stage.rs` | Main lesson display | use_lesson, use_midi, use_evaluation |
| `lesson_select.rs` | Lesson picker UI | use_lesson (list) |
| `practice_mode.rs` | Game mode controller | use_midi, use_evaluation, use_playback |
| `results_view.rs` | Session results screen | use_statistics |

## 🔵 src-tauri/ - Backend (Tauri/Rust)

**Purpose:** Native Rust backend with MIDI support, YAML parsing, and SQLite.

```
src-tauri/
├── Cargo.toml              # Backend dependencies (tauri, midir, serde_yaml, sqlx)
├── tauri.conf.json         # Tauri application configuration
└── src/
    ├── main.rs             # Tauri entry point - registers commands
    ├── lib.rs              # Library exports
    ├── config.rs           # Application configuration
    ├── lesson_parser.rs    # YAML parsing logic
    ├── commands/           # Tauri command handlers
    ├── services/           # Business logic services
    ├── models/             # Backend data structures
    └── utils/              # Utility functions
```

### 📡 src-tauri/src/commands/ - Tauri Commands

**Purpose:** IPC handlers called from frontend via `invoke()`.

| File | Purpose | Commands |
|------|---------|----------|
| `lesson.rs` | Lesson loading | `load_lesson`, `list_lessons` |
| `midi.rs` | MIDI device control | `get_midi_devices`, `start_midi_listening`, `stop_midi_listening` |
| `evaluation.rs` | Note checking | `check_note`, `get_evaluation_settings` |
| `playback.rs` | Playback control | `start_playback`, `stop_playback`, `set_tempo` |

## 📚 lessons/ - YAML Lesson Files

**Purpose:** Lesson content in YAML format.

| File | Description | Notes |
|------|-------------|-------|
| `alphabet.yaml` | C-D-E-F-G-A-B progression | Single hand, beginner |
| `simple_chords.yaml` | Basic chord progressions | C-F-G-Am chords |
| `two_hand_chords.yaml` | Separated hand practice | Left + Right hand |
| `happy_birthday.yaml` | Full melody | 8 measures |
| `example_features.yaml` | All YAML features demo | Accidentals, rests, chords |
| `README.md` | YAML format documentation | |

**YAML Structure:**
```yaml
title: "Lesson Name"
description: "Optional description"
settings:
  tempo: 120
  time_signature: "4/4"
  key_signature: "C major"
measures:
  - notes:
      - midi: 60           # Single note
      - midi: [60, 64, 67] # Chord
      - rest: 1.0          # Rest
```

## 🏃 Running the Project

### Frontend Only (Browser MIDI)
```bash
cd src-leptos
trunk serve --port 3002
# Open http://127.0.0.1:3002
```

### Full Tauri App (Native MIDI)
```bash
# First install Tauri CLI
cargo install tauri-cli

# Run full app
cargo tauri dev
```

## 🔗 Key Relationships

```
┌─────────────────────────────────────────────────────────────────┐
│                         USER INTERFACE                          │
├─────────────────────────────────────────────────────────────────┤
│  Containers (lesson_stage, practice_mode)                       │
│       │                                                         │
│       ├── use Hooks (use_lesson, use_midi, use_evaluation)      │
│       │                                                         │
│       └── render Organisms (grand_staff, timeline_viewer)       │
│               │                                                 │
│               └── render Molecules (note, measure)              │
│                       │                                         │
│                       └── render Atoms (notehead, stem, clef)   │
├─────────────────────────────────────────────────────────────────┤
│                         COMMUNICATION                           │
├─────────────────────────────────────────────────────────────────┤
│  Hooks call Tauri Commands via invoke()                         │
│       │                                                         │
│       └── Commands (load_lesson, check_note, get_midi_devices)  │
├─────────────────────────────────────────────────────────────────┤
│                         BACKEND LOGIC                           │
├─────────────────────────────────────────────────────────────────┤
│  Commands call Services                                         │
│       │                                                         │
│       └── Services (lesson_parser, midi_input, evaluation)      │
│               │                                                 │
│               └── use Models (Note, Lesson, MidiEvent)          │
│               │                                                 │
│               └── use Utils (midi_to_position, note_naming)     │
├─────────────────────────────────────────────────────────────────┤
│                         DATA SOURCES                            │
├─────────────────────────────────────────────────────────────────┤
│  lessons/*.yaml     │     MIDI Device (midir)     │   SQLite    │
└─────────────────────────────────────────────────────────────────┘
```
